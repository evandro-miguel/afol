# Knowledge Layer

This folder exists to support low-token discovery of prior workbench knowledge.

## Purpose

- Help agents reuse earlier research instead of repeating exploration.
- Provide concise search and index entrypoints for research-bearing session artifacts.

## Source Artifacts

- `docs/plans/**/_research_*.md`
- `docs/plans/**/_brainstorm_*.md`
- `docs/plans/**/_explorer-check_*.md`
- `docs/plans/**/_report_*.md`
- `docs/plans/**/_postmortem_*.md`

## Commands

```bash
.agents/agents knowledge list
.agents/agents knowledge search runtime
.agents/agents knowledge show 260306_primary-runtime-compatibility_research_01
.agents/agents knowledge index
```

- `INDEX.md` is generated by `agents-knowledge.py index`.
