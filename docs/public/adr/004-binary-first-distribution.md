# ADR-004: Binary-first public distribution

Status: superseded by [ADR-006](006-source-only-alpha.md)

This historical decision described a binary-first release model. It no longer
defines the AFOL alpha: the current release contract is source-only under
[ADR-006](006-source-only-alpha.md). Keep this record so the change in release
policy is explicit; do not use it as installation guidance.
