# Evolution Needs Live Behavioral Convergence

## Context

AFOL Evolve initially passed static validation but failed repeated fresh-agent
runs on the current repository. Agents stopped at a stale derived-state schema,
missed the read-only backfill, used unsafe optional-file globs, invented fragile
pagination reducers and artifact classifiers, and conflated project degradation
with failure of an independent historical evidence lane.

## Lesson

A learning mechanism is not ready because its prompt and fixtures look correct.
It must run against the project's real historical distribution, preserve exact
coverage and skips, and continue through independent evidence lanes when one
derived surface is unavailable. Each failed held-out run should become a tested
helper, explicit contract, or product fix before the next run.

## Prevention

- Require a fresh-agent live run after every material AFOL Evolve revision.
- Record rejected, inconclusive, and adopted experiments in the skill's
  append-only improvement log.
- Prefer tested bounded inventory and aggregation helpers over ad hoc shell
  reducers or filename assumptions.
- Keep projection, backfill preview, and canonical artifact audit statuses
  independent, with explicit coverage, skips, and current-state cross-checks.
- Stop the improvement loop only after both behavioral evaluation and an
  independent critic report no material gap.
