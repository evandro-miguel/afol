# Lesson Entries

This folder stores one lesson per file.

## Naming

Use:

- `YYYYMMDD_HHMM_<slug>.md`

Examples:

- `20260223_1716_language-policy-english-default.md`
- `20260223_1720-updated-at-script-only.md`

## Rules

- One lesson per file
- YAML frontmatter required
- Use stable, descriptive slug names
- Keep `updated_at` changes script-driven (no manual edits)

## Recommended fields

- `doc_type: lesson_entry`
- `id`
- `status`
- `created_at`
- `updated_at`
- `tags`
