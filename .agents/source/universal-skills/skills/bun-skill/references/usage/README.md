# Bun User Mode: Runtime & CLI

## Quick Reference

| Command | Description |
| :--- | :--- |
| `bun run dev` | Start dev server (fast startup) |
| `bun test` | Run tests (Vitest-compatible, native speed) |
| `bun install` | Fast package manager |
| `bun build` | Bundle for browser/node |
| `bunx <pkg>` | Execute binaries |
