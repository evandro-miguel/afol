## Common COM Errors and Solutions

### 1. **Wrap Everything in Try/Catch**

```autohotkey
#Requires AutoHotkey v2.0

try {
    xl := ComObject("Excel.Application")
    xl.Visible := true
    wb := xl.Workbooks.Add()
    ; ... your code ...
}
catch as e {
    MsgBox("COM Error: " e.Message "`n`nEnsure Excel is installed and not busy.")
    
    ; Cleanup
    if IsSet(xl) {
        try xl.Quit()
    }
}
```

### 2. **Check if Excel is Installed**

```autohotkey
try {
    xl := ComObject("Excel.Application")
    xl.Visible := true
}
catch as e {
    MsgBox("Failed to start Excel. Is it installed?`nError: " e.Message)
    ExitApp()
}
```

### 3. **Use Safe Cleanup Pattern**

```autohotkey
xl := ""
wb := ""
ws := ""  ; Release COM objects when done
```

### 4. **Check Properties Before Accessing**

```autohotkey
try {
    xl := ComObject("Excel.Application")
    if xl.HasProp("Visible")
        xl.Visible := true
}
catch as e {
    MsgBox("COM error: " e.Message)
}
```

### 5. **Complete Safe Wrapper Pattern**

```autohotkey
class ExcelApp {
    app := ""
    workbook := ""
    worksheet := ""
    
    __New(visible := true) {
        try {
            this.app := ComObject("Excel.Application")
            this.app.Visible := visible
        }
        catch as e {
            MsgBox("Failed to start Excel. Is it installed?`nError: " e.Message)
            throw e
        }
    }
    
    __Delete() {
        this.Quit()
    }
    
    Quit() {
        if this.workbook {
            try this.workbook.Close(false)
        }
        if this.app {
            try this.app.Quit()
        }
        this.app := ""
    }
}

; Usage
xl := ExcelApp(true)
try {
    xl.app.Workbooks.Add()
    ; ... work with Excel ...
}
finally {
    xl.Quit()  ; Always cleanup
}
```

## Most Common Causes

1. **Excel not installed** - Verify installation
2. **Excel is busy** - Add delays or check if Excel is responsive
3. **Permission denied** - Run script as administrator
4. **32/64-bit mismatch** - Use matching architecture (AHK and Office)
5. **Corrupted COM registration** - Repair Office installation
