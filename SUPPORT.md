# Support

- Bugs: use the bug report form with a minimal reproduction.
- Feature requests: use the feature request form and describe the user outcome.
- Documentation: use the documentation issue form.
- Release installation problems: use the release problem form.
- Vulnerabilities: use private vulnerability reporting, never a public issue.

Support is best-effort during the alpha. Linux x64 is the supported release
target. WSL2 and experimental Windows may receive diagnostic help without a
compatibility guarantee. Support does not establish hosted, macOS, or ARM
compatibility.
