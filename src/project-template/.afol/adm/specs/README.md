# Specs

- Store feature specs here (`.afol/adm/specs/*.md`).
- Keep one parent spec per feature and child specs for bounded slices when needed.
- Link roadmap features to their governing parent spec.
- Maintain index updates in the governing workflow for every new/removed spec.
