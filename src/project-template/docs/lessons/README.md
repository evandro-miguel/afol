# Lessons

This folder stores reusable lessons learned after the project accumulates real
corrections or process gaps.

## Purpose

- Capture lessons that prevent repeated mistakes.
- Keep the repository-specific guidance short and actionable.

## Structure

```text
lessons/
├── entries/                                # One lesson per file
│   └── README.md
└── README.md
```

## When to update

Update lessons when:

- A user corrects agent behavior
- A mistake repeats
- A new guardrail is identified
- A better pattern is discovered
