## Source Use Rules

- Local product evidence wins over generic heuristics when both are valid.
  Accessibility standards and platform constraints override preference. Use
  sources to clarify implementation, not to pad recommendations. Avoid claiming
  causal improvement from a metric without checking sample size, traffic
  changes, and qualitative signals. When sources are version-sensitive, verify
  current official docs before using exact API or tooling guidance.
